## Descripción

Esta práctica contiene cinco ejercicios de programación en C++ enfocados en los fundamentos de la programación estructurada y orientada a objetos.

Los ejercicios incluyen:

1. **Calculadora de consola** — Uso de tipos primitivos, operadores y validación de división entre cero.
2. **Clasificador de calificaciones** — Uso de sentencias de control para clasificar una calificación.
3. **Procesador de cadenas** — Conteo de palabras y vocales, además de inversión de una frase.
4. **Primera clase: Estudiante** — Creación de una clase con atributos, métodos y un objeto.
5. **Interacción entre objetos: Grupo** — Uso de objetos `Estudiante` dentro de un `Grupo` para calcular el promedio general.
